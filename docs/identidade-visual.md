# Identidade Visual

## Nome do Projeto

TechMinds Education

---

## Conceito Visual

A identidade visual do projeto foi desenvolvida com o objetivo de transmitir modernidade, tecnologia, organização e educação.

A proposta visual busca criar um ambiente agradável para estudos, utilizando elementos que passem sensação de foco, acessibilidade e inovação.

O visual da plataforma será pensado para oferecer uma experiência simples, intuitiva e organizada para os estudantes.

---

## Estilo Visual

O projeto seguirá um estilo:

- moderno;
- tecnológico;
- minimalista;
- educacional.

A interface terá organização limpa para facilitar a leitura dos conteúdos e a navegação dos usuários.

---

## Logo

A logo do projeto foi desenvolvida pelo grupo para representar a união entre tecnologia e educação.

A identidade visual utiliza elementos modernos e minimalistas, buscando transmitir organização, inovação e foco nos estudos.

## Paleta de Cores

A paleta de cores foi escolhida para transmitir modernidade, equilíbrio e um ambiente agradável para estudos.

As cores principais utilizadas no projeto serão:

- #1A2601: verde escuro utilizado no fundo principal;
- #2C4001: verde oliva aplicado em menus e seções;
- #93A651: verde claro para detalhes e destaques;
- #A77E34: dourado utilizado em botões e elementos importantes;
- #40281A: marrom escuro para contraste visual;
- #757B4B: verde acinzentado em elementos secundários.

A combinação dessas cores busca criar uma identidade visual moderna, organizada e confortável para os usuários da plataforma.

---

## Fontes

O projeto utilizará fontes simples, modernas e de fácil leitura.

As fontes serão escolhidas pensando principalmente na legibilidade em dispositivos móveis e computadores.

---

## Objetivo da Identidade Visual

A identidade visual do TechMinds Education busca:

- transmitir profissionalismo;
- facilitar a navegação;
- melhorar a leitura dos conteúdos;
- criar aparência moderna;
- tornar a experiência mais agradável para os estudantes.
