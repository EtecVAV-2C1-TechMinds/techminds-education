# Mobile First

O projeto será desenvolvido utilizando o conceito de Mobile First, onde o site será planejado inicialmente para dispositivos móveis e posteriormente adaptado para telas maiores, como tablets e computadores.

A escolha desse modelo foi feita porque grande parte dos usuários acessa plataformas de estudo utilizando celulares. Dessa forma, o site busca oferecer uma navegação mais simples, organizada e acessível em diferentes tamanhos de tela.

---

# Adaptação para Celulares

O projeto pretende utilizar uma estrutura responsiva para garantir melhor visualização dos conteúdos em dispositivos móveis.

Serão utilizados:

- menus simplificados;
- organização vertical dos conteúdos;
- imagens adaptáveis;
- espaçamento adequado entre os elementos;
- navegação intuitiva;
- botões acessíveis para toque.

---

# Cuidados com o Menu

O menu será organizado de forma simples e objetiva para facilitar a navegação em telas menores.

O projeto pretende utilizar:

- menu responsivo;
- fácil acesso às páginas principais;
- organização limpa dos itens;
- navegação prática para dispositivos móveis.

---

# Cuidados com as Imagens

As imagens serão organizadas de forma responsiva para evitar problemas de carregamento e adaptação em diferentes telas.

O projeto utilizará:

- imagens ajustáveis;
- boa qualidade visual;
- organização adequada dos espaços;
- equilíbrio entre desempenho e aparência.

---

# Cuidados com os Textos

Os textos serão organizados buscando facilitar a leitura em dispositivos móveis.

Serão utilizados:

- tamanhos adequados de fonte;
- boa separação entre conteúdos;
- contraste visual;
- estrutura simples e objetiva.

---

# Organização da Tela

A estrutura do site será organizada para manter uma navegação limpa e intuitiva.

O projeto pretende manter:

- distribuição equilibrada dos elementos;
- seções organizadas;
- adaptação para diferentes resoluções;
- experiência visual acessível e moderna.
