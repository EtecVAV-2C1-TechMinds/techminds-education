# Referências

## Inspirações do Projeto

O projeto utilizou referências visuais de plataformas educacionais modernas e sites voltados para organização de estudos.

As referências foram utilizadas principalmente para auxiliar na estrutura visual, organização das páginas e experiência do usuário.

---

## Tecnologias Planejadas

- HTML5
- CSS3
- Git/GitHub
- Mobile First

---

## Conceitos Aplicados

- responsividade;
- organização visual;
- navegação simplificada;
- identidade visual moderna;
- acessibilidade.

---

## Observação

Como o projeto ainda está em fase de planejamento, os conteúdos educacionais e materiais de estudo ainda serão definidos futuramente pelo grupo.
